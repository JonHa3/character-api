# Cartoon Character API

A REST API for the cartoon characters from my CSC-340 Character Gallery static web app (Gumball, Ben 10, Aang, Dipper, Finn, and more). Built with Spring Boot using a layered architecture (Controller → Service → Repository → Entity), with data stored in PostgreSQL on Neon and deployed on Render with Docker.

## Live API

**Base URL:** https://character-api-zw3i.onrender.com/api/characters

> **Heads up:** This runs on Render's free tier, which puts the service to sleep when idle. The first request after a period of inactivity can take up to a minute while it wakes up. Requests after that are fast.

## Data Model

**CartoonCharacter** (table `characters`)

| Attribute | Type | Rules |
|-----------|------|-------|
| `characterId` | Long | Unique, auto-generated by the database |
| `name` | String | Required (not null, not blank) |
| `description` | String | Required (not null, not blank) |
| `network` | String | Optional; the network the show aired on (e.g. Cartoon Network, Nickelodeon, Disney) |
| `species` | String | Optional (e.g. Human, Cat) |
| `firstAppearance` | LocalDate | Optional; format `yyyy-MM-dd` |

## Endpoints

Base path: `/api/characters`

| Method | Path | Description | Success |
|--------|------|-------------|---------|
| GET | `/api/characters` | Get all characters | 200 |
| GET | `/api/characters/{id}` | Get one character by ID | 200 |
| POST | `/api/characters` | Add a character | 201 |
| PUT | `/api/characters/{id}` | Update a character | 200 |
| DELETE | `/api/characters/{id}` | Delete a character | 204 |
| GET | `/api/characters?network=Nickelodeon` | Filter by network (exact match, case-insensitive) | 200 |
| GET | `/api/characters?name=dip` | Search by name (partial match, case-insensitive) | 200 |

`name` and `network` can also be combined, e.g. `/api/characters?name=a&network=cartoon network`.

### Error responses

| Situation | Status |
|-----------|--------|
| ID does not exist (GET, PUT, DELETE) | 404 Not Found |
| POST or PUT with a missing or blank `name` or `description` | 400 Bad Request |

### Example: POST `/api/characters`

```json
{
  "name": "Gumball Watterson",
  "description": "A blue cat who gets into chaotic misadventures in Elmore.",
  "network": "Cartoon Network",
  "species": "Cat",
  "firstAppearance": "2011-05-03"
}
```

Response: `201 Created` with the saved character, including its generated `characterId`.

### Example: PUT `/api/characters/1`

```json
{
  "name": "Gumball Watterson",
  "description": "A mischievous blue cat from Elmore who attends Elmore Junior High.",
  "network": "Cartoon Network",
  "species": "Cat",
  "firstAppearance": "2011-05-03"
}
```

Response: `200 OK` with the updated character.

## Running Locally

1. Set the database connection string as an environment variable (never commit it):
   ```
   # Windows cmd
   set "SPRING_DATASOURCE_URL=jdbc:postgresql://..."
   # PowerShell
   $env:SPRING_DATASOURCE_URL="jdbc:postgresql://..."
   # Mac/Linux
   export SPRING_DATASOURCE_URL="jdbc:postgresql://..."
   ```
2. Start the app from the same terminal:
   ```
   ./mvnw spring-boot:run        # Mac/Linux
   .\mvnw.cmd spring-boot:run    # Windows
   ```
3. The API runs at `http://localhost:8080/api/characters`. The `characters` table is created automatically on first run.
